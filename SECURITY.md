# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Hilal, **please do not open a public issue.**

Instead, email **security@cresentrix.com** with:

- A description of the vulnerability
- Steps to reproduce
- The affected package(s) and version(s)
- Any suggested mitigations

You can expect:

- An acknowledgement within 3 business days
- A fix or status update within 14 business days
- Public disclosure coordinated with you after the fix ships

## Supported Versions

The latest minor version of each package on npm and Packagist receives security patches.

## Hall of Fame

Researchers who responsibly disclose vulnerabilities will be credited here unless they request anonymity.
